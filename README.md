### Задание 5 — Структура Rectangle
- Файл: `task5/task5.go`
- Что делает: объявляет структуру `Rectangle` с полями `Width` и `Height`,
  а также реализует метод `Area()` для вычисления площади прямоугольника.

Пример использования:

```go
r := task5.Rectangle{Width: 5, Height: 3}
fmt.Println(r.Area()) // 15
```

##Требования
####Go 1.21 или новее
####Любая IDE (VS Code, GoLand) или обычный терминал

**Как запустить
Клонировать репозиторий:

bash
git clone [ссылка-на-ваш-репозиторий]
cd lab2
Убедиться, что есть файл go.mod с именем модуля:

text
module lab2

go 1.21
Если файла нет — создать:

bash
go mod init lab2
Запустить:

bash
go run .
Точка . означает: собрать и запустить все .go-файлы в текущей папке
вместе с импортированными пакетами task1…task5.**
